# First Step Web Project 🚀

This is my very first web development project. It was created to practice the fundamentals of semantic HTML and CSS styling.

### 🎯 Key Goals:
* Learning basic HTML tags and document structure.
* Working with CSS (colors, fonts, margins, and paddings).
* Understanding the box model and simple layouts.
* Deploying a live site using GitHub Pages.

### 🛠 Tech Stack:
* **HTML5** — content structure.
* **CSS3** — visual styling.
